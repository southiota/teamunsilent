## B. 보도 카드형

비교: `B-before-*`(현재 리스트) / `B-after-{1440,1280,820,390}-{tv,news,intl,news-more}.jpg`.

### 카드 구성
- `<a>` 하나가 카드 전체(링크 하나). 순서: 썸네일 → `small`(매체 · 날짜) → `b`(제목 2줄 말줄임).
- 썸네일 16:9, 둥근 모서리 12px, 바탕 `--ink-2`. 이미지 `alt=""` + 썸네일 `span`에 `aria-hidden="true"`(제목이 링크 이름이므로 중복 낭독 방지).
- 매체·날짜: JetBrains Mono 11px, `--mute`(6.7:1), 한 줄 말줄임(모바일은 줄바꿈 허용). 기존 lime → mute로 바꿈(카드 78장에 라임이 너무 많아짐). 라임은 탭·더 보기·hover 제목에만.
- 제목: 15.5px / 700 / 1.42, `-webkit-line-clamp:2`.
- YouTube: 썸네일 가운데 재생 아이콘(46px 원, 바탕 night 72%, 테두리 paper 40%, paper 삼각형). REC 레드 쓰지 않음. 타이포 카드에서는 오른쪽 아래 34px.
- 기존 `YouTube ↗` / `기사 ↗` span은 화면에서 숨기고 보이지 않는 텍스트로 남김. 문구를 `YouTube, 새 창` / `기사, 새 창`으로 바꾸기 권장(↗ 낭독 방지).
- hover: 썸네일 scale 1.03(0.6s, `--ease`) + 제목 라임. reduced-motion에서는 확대 없음. 포커스 링 3px lime, offset 4px.
- **타이포 카드**(이미지 없는 항목): 같은 16:9 상자, `--ink-2` 바탕 + 1px `--line` 테두리, 왼쪽 아래에 매체명(Pretendard 800, clamp(19px,1.9vw,26px), paper, 괄호 부분 뺌). 장식 추가 없음.

### 그리드
| 폭 | `.rec` | 카드 |
|---|---|---|
| ≥1024px | 지금처럼 2단(왼쪽 행사 목록, 오른쪽 보도) | 2열, 간격 28px 20px. 접힘 6개 = 3줄, 왼쪽 목록 높이와 거의 맞음 |
| 600~1023px | 1단 (기존 860px 분기를 1023px로 올림) | 3열 |
| <600px | 1단 | 가로형 행: 썸네일 128px + 텍스트, 행마다 아래 1px 선 |

가로 스크롤 없음 확인(1440·1280·820·390).

### 탭·더 보기
- 그대로 유지. `#press a[data-k][data-more]` 속성과 `.js .press…` 숨김 규칙, `home.js` 그대로 동작(시안에서 확인).
- 접힘 상태 첫 6개(아래 '보이는 6개 조정')만 `data-more` 없이 둔다. 날짜순(DOM 순서)은 그대로.

### 성능
- 파일: `drafts/press-thumbs/opt/NN-*.webp`(640×360, 78장 2.3MB) → `img/press/`로 복사. 타이포 카드 34개는 파일을 복사하지 않음 → 실제 44장.
- `<img src="img/press/NN-x.webp" alt="" width="640" height="360" loading="lazy" decoding="async">`. 숨겨진(display:none) 탭·더 보기 항목의 lazy 이미지는 받지 않으므로 처음엔 탭 하나의 6장만 받는다.
- 모바일 128px 썸네일용 320×180 버전을 같이 두고 `srcset="…-320.webp 320w, ….webp 640w" sizes="(max-width:599px) 128px, (max-width:1023px) 31vw, 260px"`.
- 언론 썸네일은 grade.py 보정하지 않음(언론사 저작물이고 로고·자막이 있어 원래 모습대로 둔다).

### CSS
`drafts/design/2026-10-20-press-cards/press-cards.css`를 기존 `.press`, `.press a/small/b/span` 규칙(index.html 276~281행)과 바꿔 넣는다. 탭·더 보기 규칙(282~291행)은 그대로. 마크업은 각 `<a>` 맨 앞에 썸네일 span을 넣고, YouTube 항목에 `class="yt"`를 붙인다.
```html
<a href="…" target="_blank" rel="noopener" data-k="tv" class="yt"><span class="pt" aria-hidden="true"><img …></span><small>SBS 생방송 투데이(SBS STORY) · 2025.07.03</small><b>…</b><span>YouTube, 새 창</span></a>
<a href="…" data-k="news" data-more><span class="pt ty" aria-hidden="true"><i>문화저널21</i></span><small>…</small><b>…</b><span>기사, 새 창</span></a>
```
