## 타이포
- 서체: Pretendard Variable (fallback: Pretendard, Noto Sans KR, -apple-system, sans-serif)
- 영문 디스플레이: Archivo (width 112~125%, 800~900) — 아웃라인 워드마크, 숫자, DJ 이름. 예외: DJ 커버의 큰 이름만 좁은 폭 wdth 62% (1px 선 아웃라인)
- HUD·라벨: JetBrains Mono 11~12px, 대문자, 자간 .1em 이상
- 제목: weight 800, letter-spacing -0.03em, line-height 1.12, `text-wrap: balance`
- 본문: 17px, line-height 1.6, letter-spacing -0.01em, `word-break: keep-all`
- 영문 워드마크(SILENT / UNSILENT): 아웃라인(스트로크) 대형 타입

## 레이아웃

## 시그니처 요소
- 헤드셋 스위치: 흑백(밖) ↔ 색·빛(헤드셋 안). UN이 열리며 SILENT → UNSILENT
- 현장 시계: 타임랩스와 같이 가는 대형 시각 숫자 + 그날의 흐름
- 소음 단계 MUTE / LOW / LOUD(소음 1·3·5/5)와 소음 막대 = 무소음 / 저소음 / 언사일런트. 번호(01/03/05)는 순번으로 읽혀서 쓰지 않는다
- DJ 커버 — '헤어라인' 안으로 확정 (사용자 결정 2026-10-20, `assets/cover.css`, `tools/cover.py`). 홈 DJ 패널 오른쪽 이미지 영역과 프레스킷 상단이 같이 쓴다.
  - 큰 이름: Archivo wdth 62%, 채움 없이 1px 선(paper 32%)만
  - 누끼: 흰 테두리 없이 은은한 라임 윤곽광
  - 스티커·배지·바코드·낙서 없음. 장식은 오른쪽 아래 세로 mono 'TEAM UNSILENT · DJ 0n'(n = DJ 순번) 하나뿐
  - 왼쪽 텍스트·레이아웃·모션은 기존 그대로
  - 폐기: 이전 '스트리트 매거진 커버'(꽉 찬 라임 이름 + 흰 스티커 테두리 누끼 + 장르 스티커·숫자 배지·바코드 라벨·라임 낙서)는 쓰지 않는다
  - 사용자 피드백: 레퍼런스(핀터레스트 포스터)는 참고만. 매거진 커버안은 "너무 튀는 느낌, 약간 정갈하면" — 팀 톤은 '정갈함' 쪽
- 프레스킷 파형 띠(상단 커버 아래): 라인형(channels, 세 줄 파형)을 쓴다. bar형(deck)은 쓰지 않는다 (사용자 선호)
- DJ 화면 신규 시안 4종(A 패스 / B 콜라주 / C 검열 띠 / D 이슈 커버, `drafts/dj-v9`)은 폐기
- 레퍼런스 이미지는 `drafts/design/ref/`(git 제외)에 둔다

## 작업 방식
- DJ 영역 등 시각 변경은 같은 화면 맥락(왼쪽 텍스트 포함)에서 비교 샘플로 보여 준다. 이미지 영역만 잘라서 보여 주지 않는다.

## 모션
- 기본 이징 `--ease` cubic-bezier(.2,.8,.2,1)
- 등장: 라이즈·와이프 리빌·카운트업 위주. 튀는 바운스 금지
- `prefers-reduced-motion: reduce`에서는 모든 장식 모션 비활성

## 사진
- 배경 사진은 어둡게(brightness ≈.42, saturate ≈.6) 깔고 텍스트 대비 확보
- 관객이 주인공 — DJ 단독 클로즈업보다 관객 반응 컷 우선

### 사진 속 인물 (필수)
- 쓸 수 있는 인물은 **관객**과 **팀원 3명(DR.KTRL · KALI · LiFY)뿐**이다. 팀원 확인 기준 이미지: `img/m_ktrl.png`, `img/m_kali.png`, `img/m_lify.png`.
- **다른 공연자(게스트 DJ, MC, 타 팀)가 주인공처럼 나온 컷은 쓰지 않는다.** 부스에서 플레이 중이거나, 화면 중심에 있거나, 얼굴이 크게 알아볼 수 있게 나온 경우다. 이때 그 사람이 팀원인지 확실하지 않으면 다른 공연자로 본다.
- **스치듯 나온 사람은 신경 쓰지 않는다** (사용자 지시 2026-10-20: "저 정도 나오는 거면 굳이 그 사람이 나왔다고 해야해?"). 무대 가장자리에 서 있는 사람, 팔·옆얼굴 일부, 어두운 실루엣, 스태프·촬영 인력·행사 캐릭터가 배경으로 지나가는 정도는 누군지 확인하지 않고 그대로 쓴다. 사용자에게 묻지 않는다.
- `공연사진/` 원본에는 다른 공연자 사진이 섞여 있다. 폴더 이름의 행사가 팀 공연이라도 컷마다 확인한다.
- 다른 공연자가 걸린 좋은 컷은 다음 순서로 살린다.
  1. 크롭으로 잘라낸다.
  2. 크롭이 안 되면 agy로 인물을 지운다. 지운 자리가 어색하거나 얼굴 일부가 남으면 그 컷은 버린다.
- 스태프(명찰 착용)는 관객이 아니다. 행사 측 지급 의상(Kellogg's 재킷 등)은 신원 근거가 되지 않는다. 영상(`vid/`)도 같은 규칙을 따른다.

### 사진 톤 (톤 레시피 v1)
사이트·SNS·인쇄물에 쓰는 모든 실사 사진은 `tools/grade.py`로 톤을 맞춘 뒤 쓴다. 촬영자·장소·조명이 달라도 한 팀의 사진처럼 보이게 하는 것이 목적이다.

레시피는 고정값이 아니라 **사이트 디자인을 따라간다.** 컬러 토큰, 섹션 배경, 사진 위 텍스트 처리가 바뀌면 designer가 레시피를 다시 맞춘다. 사용자 확인 없이 진행해도 된다. 맞추는 순서는 다음과 같다.
1. 바뀐 화면에 보정 사진을 실제로 얹어 본다.
2. 상수를 조정한다.
3. 이 표, `tools/grade.py`, 버전 번호(v1 → v2)를 함께 바꾼다.
4. `img/`의 보정본을 원본에서 다시 뽑는다.

| 항목 | 값 | 의도 |
|---|---|---|
| 채도 | ×0.82 | 형광 조명이 라임 포인트와 경쟁하지 않게 |
| 대비 (S커브) | 0.32 | 중간톤에 힘을 주고 양 끝은 지킨다 |
| 그림자 → `--ink` | 0.45, 가중치 (1−L)³ | 그림자만 딥 틸로 가라앉히고 피부톤은 거의 건드리지 않는다 |
| 하이라이트 → `--lime` | 0.05, 가중치 L² | 밝은 부분에 아주 옅게만 |
| 블랙 리프트 | 0.5 (검정 → ink 절반) | 순흑 대신 사이트 바탕과 이어지는 검정 |
| 화이트 상한 | `--paper` | 순백 대신 paper |

레시피 전에 사진마다 자동 맞춤을 한다. 자동 레벨(0.5~99.9%, 절반 강도), 중간톤 화이트밸런스(절반 강도, 채널 배율 0.88~1.12), 노출(중간 밝기 0.32 목표, 감마 0.8~1.25)을 맞춘다. 조명이나 하늘이 넓은 사진은 밝기를 올리지 않는다.

- 실행: `.venv/bin/python tools/grade.py <파일|폴더> -o <출력폴더> [--long 2000] [--strength 1.0]`
- 출력: `.jpg`(q82) + `.webp`(q80). EXIF(촬영 위치 등)는 지운다. 원본은 건드리지 않는다.
- 사이트 이미지는 `img/`에 보정본만 둔다. 원본은 `공연사진/`(git 제외)에만 있다.
- 사진마다 노출이 크게 다르면 `--strength`를 0.6~1.0 사이에서 조정한다. 레시피 값 자체를 바꾸려면 이 표와 `tools/grade.py` 상수를 함께 바꾼다.
- 누끼(`*_cut.png`)는 보정한 사진에서 따야 배경과 톤이 맞는다. 이미 따 둔 투명 PNG는 `grade.py`에 그대로 넣으면 인물 영역만 보고 맞추고 알파를 유지한다(.png + .webp).
- 검은 옷 누끼는 ink 배경에 묻힌다. 뒤에 라임 방사 그라데이션을 깔고 `drop-shadow`로 1px 라임 윤곽을 준다.

## 채널 템플릿 규격
| 용도 | 크기 |
|---|---|
| 인스타 피드 | 1080×1350 (4:5) |
| 인스타 스토리/릴스 커버 | 1080×1920 (9:16) |
| OG 이미지 (링크 공유) | 1200×630 |
| 포스터 | A2 기준 비율 (420×594) |

## 접근성
- 본문 대비 4.5:1 이상 (ink 위 paper/lime 통과, mute는 보조 텍스트에만)
- 포커스 링: 3px lime, offset 4px
- 모든 이미지에 의미 있는 alt (장식용은 `alt=""`)
